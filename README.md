# Budget vs Actual Analysis

## Project Overview

This project analyzes budgeted and actual expenses over 12 months to evaluate financial performance, identify budget variances, and support business decision-making.

## Objectives

- Compare budgeted and actual expenses.
- Calculate monthly and category-level budget variances.
- Measure variance percentages and budget execution.
- Identify overspending and underspending.
- Provide recommendations for better budget management.

## Tools Used

Python · Pandas · Matplotlib · Google Colab · Data Analysis · Business Analytics

## Key Results

- **Total Budget:** 1,762,200
- **Actual Expenses:** 1,718,180
- **Budget Execution Rate:** 97.50%
- **Unspent Budget:** 44,020
- **Highest Overspending Category:** Operational Costs (+9,082; +5.50%)
- **Second-Highest Overspending Category:** Maintenance Costs (+2,487; +5.18%)

## Business Recommendations

1. Investigate operational cost overruns and identify opportunities to control spending.
2. Review maintenance expenses and assess whether budget estimates are realistic.
3. Investigate development, training, and travel underspending to distinguish genuine savings from delayed activities.
4. Continue monitoring monthly variances to improve financial planning.
